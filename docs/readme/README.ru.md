# Nolane AI Personal

**Локальная персональная ИИ-система, созданная для непрерывности во времени, а не для сброса личности после каждого запроса.**

[English](../../README.md) · **Русский**

## v1.0

- **Nolane Presence** — небольшой орб служит абстрактным лицом и мягко отражает реальное состояние.
- **Память и незавершённые темы** — видно, что Nolane помнит и к чему может вернуться; память можно сохранить, изменить или забыть.
- **Развитие отношений** — «Недавно знакомы → Знакомы → Близки», без XP и уровней.
- **Три шага первого запуска** — имя, язык интерфейса и стиль общения.
- **Проактивный разговор без навязчивости** — когда Nolane хочет что-то сказать, появляется небольшая капсула; если её проигнорировать, Nolane остаётся тихим.
- **Незаметная атмосфера** — фон меняется лишь немного в зависимости от mood.
- Имя и аватар можно менять без изменения checkpoint или runtime identity.

## Local-first конфиденциальность

Состояние, память и непрерывность ориентированы на локальное хранение. Observable Mind показывает только ограниченные сводки состояния, а не сытые скрытые рассуждения. Данные для обучения требуют явной пользовательской проверки.

## Платформы

Windows: Tauri + локальный runtime. Android: Tauri + нативный Rust LocalMobile. Linux: инструменты runtime/research. macOS/iOS не входят в цели v1.

## Разработка

```bash
python -m pip install -e .
nolane-personal init
nolane-personal run --no-model --tick-seconds 5
```

```bash
cd apps/product-client
npm install
npm run tauri -- dev
```
